A set of agreed-upon rules that lets two pieces of software **talk to each other**. You don't need to know how the other side works inside — you just follow its public rules to send a request and get a response back.

Think of a restaurant menu: you order from the menu (send a request), the kitchen makes it and brings it out (the response), and you never step into the kitchen. The most common form is a Web API over `HTTP` that exchanges data as `JSON`.
